# 🏢 ERP System

An **Enterprise Resource Planning (ERP)** system designed to integrate and manage core business processes such as **Human Resources, Finance, Sales, and Inventory**.  
The system provides both a **backend API** and a **frontend dashboard** for seamless interaction.

---

## 🚀 Features
- **User Management** – Authentication, roles, and permissions
- **Human Resources (HR)** – Employee records, payroll, leave management
- **Finance** – Invoices, expenses, revenue tracking
- **Inventory** – Stock management, suppliers, purchase orders
- **Responsive Web UI** – Easy-to-use frontend dashboard
